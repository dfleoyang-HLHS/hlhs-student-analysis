# 花中學生來源與成績

國立花蓮高級中學學生的統計網頁：在校生的畢業國中來源、特殊班、原住民族別，以及 109–115 學年度入學各屆的國中教育會考等級、會考與學測的關係、學測各屆表現。

網頁只有一個檔案 `index.html`，所有統計都已預先彙整並嵌入其中。

## 個資保護

- 本網頁只放彙整後的統計數字，**沒有任何學生的姓名、學號、身分證字號或逐筆資料**。
- 涉及報部身份、原住民族別、國中教育會考、大學學測的人數，1–2 人一律顯示為「<3」。
- 平均值至少 3 人才顯示，百分位數至少 5 人，相關係數至少 10 人。
- 國中層級的成績統計，人數不到門檻的國中合併為「其他國中」。
- 長條圖中的斜線區塊，是人數少於 3 的類別合併後的結果。
